# Ashen Rifts — Попелище

Піксельний ARPG у стилі Diablo / Dark Souls, що працює повністю в браузері (HTML5 canvas, без залежностей і без збирання).

## Що всередині

| Файл | Призначення |
|------|-------------|
| `index.html` | Уся гра в одному файлі (код, стилі, графіка малюється програмно) |
| `404.html` | Перенаправлення на гру, якщо адресу введено неправильно |
| `.nojekyll` | Вимикає обробку Jekyll на GitHub Pages, щоб файли віддавались як є |
| `README.md` | Ця інструкція |

## Публікація на GitHub Pages

1. Створіть новий репозиторій на GitHub (наприклад, `ashen-rifts`). Він може бути публічним.
2. Завантажте в корінь репозиторію **вміст** цього архіву: `index.html`, `404.html`, `.nojekyll`, `README.md`.
   - Через сайт: **Add file → Upload files**, перетягніть файли й натисніть **Commit changes**.
   - Через термінал:
     ```bash
     git init
     git add .
     git commit -m "Ashen Rifts"
     git branch -M main
     git remote add origin https://github.com/<ваш-логін>/ashen-rifts.git
     git push -u origin main
     ```
3. У репозиторії відкрийте **Settings → Pages**.
4. У розділі **Build and deployment** оберіть **Source: Deploy from a branch**, гілку **main** і папку **/ (root)**, збережіть.
5. Через 1–2 хвилини гра буде доступна за адресою `https://<ваш-логін>.github.io/ashen-rifts/`.

Щоб оновити гру, просто замініть `index.html` у репозиторії й зробіть commit.

## Керування

| Дія | ПК | Телефон |
|-----|----|---------|
| Рух | WASD / стрілки | джойстик (лівий палець) |
| Удар | ЛКМ (можна тримати) або F | кнопка удару |
| Ухилення | Пробіл або ПКМ | кнопка ухилення |
| Взаємодія | E | кнопка взаємодії |
| Фляга ХП / МП / Телепорт | Q / R / T | три кнопки в куті |
| Інвентар / Завдання | I / J | іконки |

## Збереження прогресу

Прогрес зберігається в `localStorage` браузера (окремо для кожного пристрою й адреси). Щоб почати з нуля:

- відкрийте гру з параметром: `https://<ваш-логін>.github.io/ashen-rifts/?reset`, або
- очистіть дані сайту в налаштуваннях браузера.

## Примітки

- Шрифт Press Start 2P підвантажується з Google Fonts. Без інтернету гра використає моноширинний шрифт за замовчуванням.
- Гра адаптована під телефони (вертикальна й горизонтальна орієнтація) та ПК.
- Для найкращого вигляду використовуйте сучасний браузер (Chrome, Safari, Firefox, Edge).
