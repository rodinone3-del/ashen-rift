# 🔥 Ashen Rifts: Попелище

**Піксельний ARPG у браузері в дусі Diablo та Dark Souls.**
Табір мандрівників на межі загибелі, Розломи в пустоші та Страж Попелу, що спить на дні кожного з них.

▶ **Грати:** `https://rodinone3-del.github.io/ashen-rift/`

> **English:** A dark pixel-art browser ARPG inspired by Diablo and Dark Souls. Hold the last camp, rescue survivors, delve into procedurally generated rift dungeons and uncover the truth behind the Ash Guardian. Three classes, loot and item sets, quests, full mobile support. No install, no build: a single HTML file.

---

## Можливості

- **Три класи**: Воїн, Розбійник і Маг. Кожен має свій стиль бою й унікальне ухилення (перекат, ковзання, розсипання на попіл).
- **Розломи й підземелля**: у пустоші з'являються Розломи з таймером, що ведуть у процедурно згенеровані підземелля: кімнати різної форми, потайні ходи, скрині під охороною та бос наприкінці.
- **Пустош**: велика відкрита карта з групами ворогів, міні-босами й різними видами монстрів (упирі, примари, кажани, скелети-лучники, кати).
- **Рівні й лут**: рівні гравця, ворогів і предметів, чотири рівні рідкості, сети з бонусами, невідомі предмети й ідентифікація, обмеження за рівнем.
- **Табір, що оживає**: врятуйте торговця, чаклуна й банкіра. Вони відкривають крамниці, ідентифікацію, склад і послуги.
- **Квести й сюжет**: основна лінія про Хранителя Еріка й Велику Тріщину, плюс побічні завдання від мешканців табору.
- **Живе селище**: мешканці ходять своїми справами й розмовляють навмання.
- **Піксельна графіка** без зовнішніх ресурсів: усе малюється програмно, динамічне освітлення, дізеринг.
- **Мобільне керування**: джойстик, кнопки під великий палець, адаптація під вертикальну й горизонтальну орієнтацію.

## Керування

| Дія | ПК | Телефон |
|-----|----|---------|
| Рух | WASD / стрілки | джойстик (лівий палець) |
| Удар | ЛКМ або Пробіл (можна тримати), F | кнопка удару |
| Ухилення | Shift або ПКМ | кнопка ухилення |
| Взаємодія | E | кнопка взаємодії |
| Фляга ХП / банка МП / телепорт | 1 / 2 / 3 (або Q / R / T) | три кнопки в куті |
| Інвентар / завдання | I / J | іконки |

Телепорт потребує 3 секунд зосередження, і поранення збиває його. Клавіші працюють у будь-якій розкладці (українська, англійська та інші). Фляга й банка МП мають перезарядку.

## Запуск локально

Збирання не потрібне: це один файл.

```bash
# варіант 1: просто відкрити index.html у браузері
# варіант 2: невеликий локальний сервер
python3 -m http.server 8000
# потім відкрити http://localhost:8000
```

## Публікація на GitHub Pages

1. Завантажте `index.html`, `404.html`, `.nojekyll` у корінь репозиторію.
2. **Settings → Pages → Build and deployment → Deploy from a branch**, гілка `main`, папка `/ (root)`.
3. Через 1–2 хвилини гра буде за адресою `https://<ваш-логін>.github.io/<репозиторій>/`.

## Продуктивність

Гра сама підбирає якість графіки під пристрій і, якщо в перші хвилини FPS стабільно нижчий за ~32, переходить на нижчий режим. Вручну це можна змінити в **Налаштуваннях** (іконка шестерні): 

| Режим | Що змінюється |
|-------|---------------|
| Висока | Дізеринг і палітра, багато джерел світла, плавні контури, без обмеження FPS |
| Середня | Без постобробки кадру (найдорожча операція на слабких телефонах), менше світла, до 60 к/с |
| Низька | Ще менша роздільність, без контурів і блиску, 30 к/с |

Автоматично: iPhone та ПК починають на «Високій», Android на «Середній», слабкі Android (до 4 ГБ пам'яті чи 6 ядер) на «Низькій».

## Збереження

Прогрес зберігається в `localStorage` браузера (окремо для кожного пристрою й адреси). Щоб почати спочатку, відкрийте гру з параметром `?reset` або очистіть дані сайту.

## Технології

HTML5 Canvas, чистий JavaScript без залежностей, рендер у низькій роздільності з постобробкою (палітра й дізеринг), `localStorage` для збережень. Шрифт Press Start 2P підвантажується з Google Fonts.
